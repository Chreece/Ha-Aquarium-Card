# Changelog

## 0.2.1

- Give feeder and TDS separate responsive layout rows, preventing overlapping icons and click targets in narrow dashboard columns.
- Remove backgrounds, borders and blur panels from scene icons, equipment controls and warnings. Preserve subtle colored icon glows and keyboard focus outlines.
- Keep invisible click targets at least 44 pixels wide and high.
- Add 21 browser layout scenarios covering narrow cards, long names, multiple warnings, unavailable entities, hover/focus states and native entity-detail clicks.
- Keep the standalone HACS module generated from editable scene CSS; no extra runtime dependencies.
